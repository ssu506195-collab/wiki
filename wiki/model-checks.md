# Workbench 結果閱讀與網格檢查

頻率、振型、模型假設要一起核對。

## C10
Workbench 的 Modal（模態分析）需要材料的質量與剛性、幾何、網格及合理拘束，再查看頻率與振型。

適用範圍：2024 R2 Mechanical；本課為概念閱讀導覽，不聲稱已執行 ANSYS。
來源：S01

## C11
網格細化時應比較關注的結果；材料或拘束錯誤不能靠網格更細修正。

適用範圍：本課以同一物理振型的頻率變化作手動檢查，不宣稱固定百分比適用所有研究。
來源：S06

## 補充與教學推導
先記錄材料、單位、拘束與連接，再追蹤相同物理振型的頻率變化。若階數交換或簡併，需進一步比對形狀，不能只比第 n 列。此為教學檢查建議，不是已通過收斂的模擬紀錄。
