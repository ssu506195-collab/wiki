# 重現提示詞
以下供後續重建使用，不冒充外部 API 呼叫紀錄。LLM 是本次對話中的 ChatGPT；腳本僅做 ingest、檢索、檢查與渲染。

1. 查讀來源：確認來源作者、版本、章節與適用範圍；以自己的話做來源筆記，不整篇複製文件。
2. 建立 Wiki：將筆記整理為 claims，每句附來源 ID 與限制，再建立互相連結的條目，保留 backlinks。
3. 查詢：針對教學問題查 Wiki。找不到主張時補資料，不直接編造答案。
4. 教學大綱：以初學者為對象，從頻率與振型逐步到共振及結果判讀，每頁附 Wiki ID、claim ID。
5. 內容檢查：檢查單位、條件、三維階次、顯示倍率與共振用語，缺依據回 Wiki。
6. HTML：以可離線使用的簡報呈現，附解析圖表與必要限制；所有技術頁可追到原始來源。
7. 檢查：執行引用與本地連結、數學測試及瀏覽器檢查。反思僅採實際 records；不可宣稱程式執行過 ANSYS 或外部 LLM。
